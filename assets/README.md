## Capture guidelines

- Prefer **16:9** screenshots, ideally around **1600×900** or **1920×1080**.
- Keep the application itself as the focus; crop unnecessary browser chrome where possible.
- Use the portfolio/demo dataset only.
- Check every screenshot for tenant names, company logos, user emails, SharePoint URLs and browser-history information before upload.
- Avoid showing Power Apps Studio formulas containing tenant-specific values.
- Do not upload screenshots that contain real Outlook conversations or real SharePoint documents.
