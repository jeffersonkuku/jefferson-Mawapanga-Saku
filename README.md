## 🧠 Ma logique de conception / My design logic

🇫🇷 Je commence par **ce que l’utilisateur doit réussir à faire**, puis je construis la donnée, l’automatisation et la sécurité autour de ce parcours.  
*🇬🇧 I start with **what the user needs to achieve**, then build data, automation and security around that journey.*

```mermaid
flowchart LR
    A[Utilisateur<br/>User] --> B[Écran simple<br/>Simple screen]
    B --> C[Données partagées<br/>Shared data]
    B --> D[Automatisations<br/>Automations]
    D --> C
    C --> E[Historique / KPI<br/>History / KPIs]
```
