# Industrial Financial Performance Dashboard

## Overview

This Power BI portfolio project simulates the financial and procurement steering of a **large multi-site industrial production environment**.

The report was designed as an executive and operational dashboard: the objective is to make complex financial information readable quickly while keeping enough detail for finance, procurement and operations teams.

## Dashboard scope

The report contains four main views:

1. **Financial 360°** — global budget, commitments, receipts, invoicing and remaining budget.
2. **Budget trajectory** — monthly execution and budget consumption monitoring.
3. **Suppliers & commitments** — supplier concentration, commitments and operational status.
4. **Transactions** — detailed purchase-order level analysis.

## Portfolio dataset

The dataset is fully synthetic and built to resemble a realistic industrial operating environment.

- 4,636 transaction lines
- 68 suppliers
- 18 industrial sites
- 4 operating regions
- Multi-year history from 2020 to 2026
- 2026 YTD: approximately €29.0M committed
- 2026 YTD: approximately €25.6M received
- 2026 YTD: approximately €23.8M invoiced
- 2026 YTD: approximately €2.3M overdue / pending

Supplier names, sites, buyers, projects, entities and financial values are fictional portfolio data.
