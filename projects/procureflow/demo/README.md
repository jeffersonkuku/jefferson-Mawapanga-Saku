# Demo video

Place the final portfolio walkthrough in this folder as:

`procureflow-demo.mp4`

## Recommended walkthrough

Target length: **2–4 minutes**.

Suggested sequence:

1. **Home & navigation** — show the application structure in a few seconds.
2. **Create a request** — select a request type and enter synthetic information.
3. **Review & submit** — show validation and the final summary.
4. **Team queue** — show the request arriving in the service queue.
5. **Accept / assign** — demonstrate ownership and status transition.
6. **Ticket detail** — show status, comments, history and stakeholder information.
7. **Documents** — show the document experience using demo files only.
8. **Email / SharePoint integration UX** — demonstrate the interface without opening any real tenant data.
9. **Closure** — show the final state / archive behaviour.
10. **Technical closing screen** — briefly show the architecture diagram from this repository.

## Recording rules

Before recording:

- use only the sanitised demo application;
- disable browser notifications;
- close Outlook / Teams / production SharePoint tabs;
- verify that no company logo, tenant URL or real email is visible;
- use synthetic names, suppliers, ticket numbers and documents;
- avoid opening Power Apps Studio areas that display production connections.
